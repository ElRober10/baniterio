# Mobile

Módulo reservado para Kotlin Multiplatform + Compose Multiplatform.

La plantilla se creará desde Android Studio cuando iniciemos la parte móvil. El código compartido consumirá la API de `back/`; Android se desarrollará en Windows y la compilación/firma iOS se realizará posteriormente en macOS con Xcode.
